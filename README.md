# QA-Testing

This repository demonstrates simple test projects. The latest addition is a web-based calendar app that lets you add events with optional reminders.

## Calendar App

The app resides in the `calendar-app` directory and consists of static HTML, CSS and JavaScript. To run it, open `index.html` in any modern web browser. Events are stored in the browser's local storage so your entries persist between visits.

### Features

- Add events with date and time
- Optional reminder minutes before the event
- List existing events and delete them

Reminders appear as browser alerts when the configured time is reached while the page is open.
